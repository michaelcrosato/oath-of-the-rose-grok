# Side quests

Fourteen independent side quests for Oath of the Rose. Each one anchors to a place already in the game and then stays in its own room, argument, or shoreline. None of them is required for the rebellion, and none of them changes what the main plot already does.

They do not depend on each other. The Gatrea courier, the Rebel Armband, Heron Glade, and the Alarm Clock are unchanged.

| Quest | Touchpoint | Activity |
| --- | --- | --- |
| The Salt Book | Paloom | Decide what a second harbor ledger is allowed to remember |
| The Humming Skiff | Poft | Finish, launch, or burn an unfinished boat that hums in storms |
| The Noon Stick | Salamand | Settle two families' claim on a desert seep |
| The House That Knocks | Bafsk | Investigate a bricked house that copies knocks |
| The Star Not in the Sky | Mysidia | Prove a logged star is a harbor buoy in a nicked lens |
| The Cold Egg | Chocobo Forest | Care for a nest the riding bird does not keep |
| The Third Cot | Altair | Choose what happens to a wounded deserter who knows nothing useful |
| The Last Firing | Fynn | Fire one oven and decide where the last loaves go |
| The Lee Fire | Snow Cavern | Reach a signal on the snow's edge and choose whether to answer it |
| What the Rocks Kept | Castle Deist | Read one household's unsent letters and choose their resting place |
| The Opener's Purse | Coliseum | Fight, free, or buy out the beast kept for the cheap start of the card |
| The Shoal Glass | Tropical Island | Listen to voices in sea-glass and choose whether they stay |
| The Last Humming Tree | Gatrea | Find why an orchard's bees left every tree but one |
| The Second Mouth | Semitt Falls | Answer, bend, or refuse a fishing song in the pools above the mine |
